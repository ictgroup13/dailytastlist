DAILY TASK MANAGER

Digital Task Tool

A practical demonstration of a web application to add, manage, edit, and delete daily tasks using Local Storage.

01

Project Requirements

  • Create a digital task manager where users can write, edit, organize, and delete daily tasks.
  • Add new tasks.
  • Display all saved tasks.
  • Edit existing tasks.
  • Delete tasks.
  • Mark tasks as completed.
  • Store tasks using Local Storage.
  • Display task statistics (total and completed).
  • Prevent saving empty tasks.
